# Commits and pull requests

Apply this whenever creating a commit or a pull request. Still follow the repository git safety rules: do not change git config, do not skip hooks, do not force-push, and do not amend unless those rules allow it.

## Author

Every commit must be authored by:

- Name: `nur-alam`
- Email: `nuralam862@gmail.com`

Do not run `git config`. Pass the identity only for that command:

```bash
GIT_AUTHOR_NAME='nur-alam' \
GIT_AUTHOR_EMAIL='nuralam862@gmail.com' \
GIT_COMMITTER_NAME='nur-alam' \
GIT_COMMITTER_EMAIL='nuralam862@gmail.com' \
git commit -m "$(cat <<'EOF'
Commit message here.

EOF
)"
```

After the commit, run `git log -1 --format='%an %ae'` and confirm it prints `nur-alam nuralam862@gmail.com`.

Open the pull request with `gh` while authenticated as `nur-alam`. Confirm with `gh api user --jq .login` before `gh pr create`.

## Wording

Commit messages, pull request titles, and pull request bodies are plain sentences about the change.

Do not keep text like "made with cursor" or any similar sentence. That includes "Made with Cursor", "Generated by Cursor", "Co-authored-by: Cursor", "Made with Claude", "Generated by Claude", "Co-authored-by: Claude", and other tool attribution.

After committing, read `git log -1 --format='%B'`. If that attribution was added, and the commit was just created, has not been pushed, and removing the attribution is the only edit, amend the message with a new message that omits it. Do not amend for any other reason.
